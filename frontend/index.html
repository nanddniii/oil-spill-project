System Pipeline

Seven sequential stages are executed for each SAR image submitted to the system.

01
INPUT
SAR Detection
Processes the uploaded Synthetic Aperture Radar (SAR) image to identify pixel regions with backscatter signatures characteristic of surface oil films. A threshold-based segmentation approach extracts the candidate spill mask.
Spill mask Confidence score
02
GEOMETRY
Spill Geometry
Computes the spatial extent and shape of the detected spill mask: total area (kmÂ²), a polygon boundary, and centroid coordinates. This geometry is used by all downstream stages.
Area (kmÂ²) Polygon Centroid
03
ESTIMATION
Oil Quantity Estimate
Estimates the approximate quantity of oil from the detected spill area and a range of assumed film thickness values (thin sheen to emulsified slick). Output is a volume range (mÂ³) and mass range (tonnes).
Volume range (mÂ³) Estimate only
04
RECONSTRUCTION
Origin Reconstruction
Applies a Lagrangian back-propagation model to the spill centroid, using wind and current parameters to reverse-trace the drift trajectory and estimate a probable source region and time window.
Origin point Uncertainty radius Time window
05
AIS
AIS Correlation
Cross-references the reconstructed origin region and time window against synthetic AIS vessel tracks. Vessels whose tracks intersect the origin window are flagged as candidates.
Candidate vessels Synthetic AIS data
06
SCORING
Candidate Ranking
Scores each candidate vessel (0â€“100) based on a weighted combination of: proximity to reconstructed origin, trajectory alignment with drift vector, AIS signal gaps, and vessel type risk profile.
Ranked candidates Score breakdown
07
FORECAST
Drift / Forecast
Projects the current spill boundary forward in time using the same drift model (wind and surface current vectors) to produce a +6 h predicted spread polygon. Rendered on the map as a dashed overlay.
+6h spread polygon Map overlay
