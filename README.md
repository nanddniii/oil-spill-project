# Oil Spill Project

## Requirements

- Node.js 18 or newer
- npm

## Setup

Clone the repository and open the project folder:

```powershell
cd oil-spill-project
npm install
```

## Run the website

```powershell
npm start
```

Open:

```text
http://localhost:3000
```

## Development mode

```powershell
npm run dev
```
